# Media Compass 🧭 - UNESCO Hackathon 2026

## 🌟 Vision
Media Compass est un assistant d'intelligence numérique responsable conçu pour les jeunes en RDC. Basé sur le cadre de la **Transmission Humaine™** et la doctrine **EDECC™**, il permet de co-analyser les contenus viraux avec une IA transparente.

## 🛠 Stack Technique
- **Frontend :** React 18 (TypeScript) + Vite
- **Styling :** Tailwind CSS + Lucide Icons
- **Backend :** Supabase (PostgreSQL + Edge Functions)
- **IA :** OpenAI GPT-4o-mini (Explainable AI logic)
- **APIs Techniques :** WhoisXML (Réputation) & PesaCheck (Fact-checking)

## 🏗 Structure
- `/frontend` : Application React (Interface utilisateur et co-analyse)
- `/supabase` : Logique serveur, base de données et orchestration IA
